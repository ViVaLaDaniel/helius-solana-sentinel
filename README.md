## 🧩 Features
- **Real-time Activity:** Monitor live transactions and smart contract interactions with human-readable parsing.
- **Portfolio Insights:** Track NFTs, tokens, and compressed assets using Helius Digital Asset Standard (DAS).
- **Security Scanning:** Detect address poisoning and malicious MEV patterns automatically.

## 🛠️ Stack
- **Next.js 14** (App Router)
- **React 18**
- **Helius SDK**
- **Tailwind CSS 3**
- **Framer Motion**
- **Biome** (Linter & Formatter)

## 📦 Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/ViVaLaDaniel/helius-solana-sentinel.git
   cd helius-solana-sentinel
   ```
2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```
3. Add your Helius API Key:
   Create a `.env.local` file in the root directory:
   ```env
   NEXT_PUBLIC_HELIUS_API_KEY=your_api_key_here
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
